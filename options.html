open-os Extension Options

Open-source browser extension for Chromium-based browsers (Chrome, Brave, Edge) that connects you to local AI models while you browse. Private, fast, and fully offline.

Powered by Ollama — compatible with Llama 3, Phi-3, Mistral, Gemma, and any model available in the Ollama library.

Click the extension icon to open the side panel, or right-click to launch in a new tab.

Created and maintained by @luishg


Getting started
  • Download and install Ollama: ollama.com
  • Pull a model from your terminal, e.g. ollama run llama3:8b
  • Make sure Ollama is running, then open the extension and start chatting
